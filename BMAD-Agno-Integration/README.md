# 全功能本地化AI智能体大整合框架

## 项目概述

本项目是一个完全本地化的AI智能体整合框架，整合了以下核心组件：

- **Agno多智能体框架** - 智能任务调度与协作
- **BMAD-METHOD开发方法论** - 敏捷开发流程
- **NeuralAgent视觉模块** - 多模态视觉理解
- **语音交互系统** - 语音识别、合成与分析
- **APISIX网关** - 统一通信层

## 架构设计

## 快速开始

### 环境要求

- Python 3.10+
- Node.js 20+
- PostgreSQL 15+ (可选)
- 16GB+ RAM (推荐32GB)
- 100GB+ 存储空间

### 安装依赖

```bash
# 安装Python依赖
pip install -r requirements.txt

# 安装Node.js依赖
npm install
```

### 运行框架

```bash
# 启动所有服务
./start-all.sh

# 或单独启动各组件
python agno/src/main.py
node bmad/src/main.js
```
